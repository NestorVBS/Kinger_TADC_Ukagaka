# Kinger Ukagaka/Ghost

🌎 ESP [Leer en Español](docs/README.md)

## 📖 **Please Read**

Kinger Ukagaka is based on the character **Kinger** from *The Amazing Digital Circus*, created by **Gooseworx** and produced by **GLITCH Productions**.

Kinger is a playful, eccentric, and somewhat clumsy desktop companion. Besides interacting with him, he also includes several features designed to keep you company while you work or study.

## 🎮 **Features**

Kinger can:

- ✊ Play **Rock, Paper, Scissors**.
- 🎬 **Watch videos together**.
- 📝 Keep track of your **to-do list**.
- 📊 Display a **usage summary**.
- 🗑️ **Empty the recycle bin**.
- 💬 Interact with you through different dialogues and events.
- 🌎 Available in **English and Spanish**.
- ⏰ Remind you about pending tasks.
- 🎂 Remember your birthday.
- 🖥️ React to different desktop events and situations.

## 📌 **Installation Guide**

Follow these steps to install Kinger on your PC:

1. 📥 **Download** the Kinger `.nar` file from this repository.

2. 🔗 **Download and install** **SSP** from its [official website](http://ssp.shillest.net/).

![download button](https://ssp.shillest.net/image/download_full.png)

3. ▶️ **Run** `ssp.exe`.

4. 👻 A character (Ghost) speaking Japanese will appear. *Don't worry about this.*

5. ⚙️ **Change the SSP language:**
   - Right-click the character.
   - Go to **“Language”**.
   - Select **“English”**.

6. 🖱️ **Install Kinger:**
   - Drag the downloaded `.nar` file.
   - Drop it onto the character currently running in SSP.

7. 🔄 **Change Ghost:**
   - Right-click the character.
   - Go to **“Change Ghost”**.
   - Select **“Kinger”**.

8. ⭐ **Always on top (optional):**
   - Right-click the character.
   - Go to **Options → Preferences**.
   - Find **Ghost(2)**.
   - Check ✅ **Always Show Foreground**.

That's it! Kinger should now appear on your desktop.
